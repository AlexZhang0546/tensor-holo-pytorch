# UNet 达到论文效果：目标与证据链

目标：用 `ComplexUNet` 架构达到原论文（TensorHolo V2，Light: Sci Appl 2022）Table 2
口径的 pre-encoding 指标：`SSIM_img ≥ 0.94` / `SSIM_amp ≥ 0.94`（论文 0.942 / 0.945）。

## 指标口径（与论文一致）
- pre-encoding `SSIM_amp`：网络输出复数场的振幅 vs 目标全息图振幅（`data_range=1.0`）。
- pre-encoding `SSIM_img`：网络输出（理想场，不经 DPM）的 15 个最频深度 + 5 个随机深度
  焦栈平均 SSIM（`data_range=1.0`）。
- 论文 Table 2 脚注确认：无括号 = 振幅图；括号 = 15+5 焦栈平均。

## 关键实测数字（论文口径，100 验证样本）

| 模型 | SSIM_amp | SSIM_img | PSNR_img | 备注 |
|---|---|---|---|---|
| holonet stage1(260ep) | 0.938 | 0.937 | 30.25 | 全分辨率 299K 参数 |
| holonet + SSIM 损失 | **0.9408** | **0.9399** | 30.31 | 加 SSIM 后达论文水平 |
| UNet stage1(400ep) | 0.906 | 0.906 | 28.74 | depth3, 3.5M 参数 |
| UNet + SSIM 损失(9 种配置) | ~0.925-0.931 | ~0.930 | ~29.8 | 全部平台在 ~0.93 |
| 论文 Table 2 Ours(RGB-D) | 0.945 | 0.942 | 28.9 | holonet + 3000 epoch |

## 单样本快速验证（架构+损失正确性）
- 从已训练 UNet 出发、冻结 BN 运行统计、SSIM 损失，单样本 500 步：
  `SSIM_img` 0.777 → **0.988**（w50）。
- 结论：UNet 有足够表达能力，损失与优化路径正确。
- 全新随机初始化单样本过拟合仅到 ~0.63（batch=1 复数 BN 白化不稳定，非架构问题）。

## 已测试的配置（多样本，全部平台 ~0.93）
| 配置 | 验证 SSIM_img |
|---|---|
| 无 SSIM（400ep） | 0.915 |
| SSIM w10, batch2, lr3e-5 | 0.925 |
| SSIM w30, batch4 | 0.930 |
| 冻结 BN, w30, lr1e-4 | 0.931 |
| 确定性深度采样, w30 | 0.9305 |
| 冻结 BN, w30, lr3e-4 | 0.928 |
| SSIM w50, batch4 | 0.930 |
| 训练集 vs 验证集 | 0.931 vs 0.928（无过拟合） |
| 验证集分布 | max 0.950 / p50 0.929 / 最差 0.895 |

## 诊断结论
1. 管线可达 0.94：holonet + SSIM 损失 = 0.940（对照实验）。
2. UNet 卡 0.93：9 种训练配置全部平台，train≈val（非过拟合），单样本 0.988（容量足）。
3. 输出高频差异：UNet 输出梯度能量/GT = 0.917，holonet = 0.937 —— UNet 略"软"，
   与 SSIM 差距方向一致（下采样丢失高频的候选证据）。
4. UNet 的差距来自多样本泛化，而非容量/损失/优化器（均已验证）。
